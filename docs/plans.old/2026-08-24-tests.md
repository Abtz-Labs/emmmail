# Plan: tests.php — TDD Catch-up + Test Suite

**Status:** done
**Date:** 2026-08-24

---

## Problem

`index.php` (6271 LOC) was built without tests. TDD principle violated. Writing `tests.php` now to validate existing code and prevent regressions.

## Scope

### 1. Create `tests.php`

Self-contained test runner — `php tests.php`, no external frameworks.

**Structure:**
```
tests.php
├── Bootstrap (require index.php, override DB path to temp file)
├── Helpers (assert*, assertEquals, assertThrows, group/test runners)
├── Unit tests — pure functions, no I/O
│   ├── .env parser (parseEnvFile)
│   ├── Encryption round-trip (encryptPassword / decryptPassword)
│   ├── Schema creation (initDatabase — DB integration but deterministic)
│   ├── IMAP folder role detection (ImapClient::detectRole)
│   ├── IMAP tokenizer (ImapClient::tokenize — via ReflectionMethod)
│   ├── IMAP fetch item parser (ImapClient::parseFetchItems — via ReflectionMethod)
│   ├── MIME parser (parseMimeMessage — simple, multipart, nested, attachments, charset)
│   ├── Header parsing (parseRawHeaders, headerValue)
│   ├── Boundary extraction (extractBoundary)
│   ├── MIME part splitting (splitMimeParts)
│   ├── Transfer encoding (decodeTransfer — base64, quoted-printable, 7bit)
│   ├── Charset conversion (convertCharset)
│   ├── MIME header decoding (decodeMimeHeader — RFC 2047 B/Q encoded words)
│   ├── Address parsing (parseAddresses — name+email, bare email, mixed)
│   ├── Filename sanitization (sanitizeFilename)
│   ├── Date normalization (normalizeDate)
│   ├── RFC 2231 decoding (decodeRfc2231)
│   ├── Blocked attachment check (isBlockedAttachment)
│   ├── Header value cleaning (cleanHeaderValue)
│   ├── Header encoding (encodeHeader — ASCII passthrough, UTF-8 B encoded)
│   ├── HTML escaping (escapeHtml, escapeAttr)
│   ├── Subject normalization (normalizeSubject — strips Re:/Fwd: etc.)
│   ├── Display name derivation (deriveDisplayName)
│   ├── Recipient sanitization (sanitizeRecipients)
│   └── Address list formatting (formatAddressList)
├── Integration tests — DB operations
│   ├── Account insert + fetch + delete
│   ├── Message store + retrieve + thread creation
│   ├── Thread aggregation (unread count, starred, preview)
│   ├── Contact upsert (use_count increment)
│   ├── Tag CRUD + message-tag association
│   ├── Draft save + list + delete
│   ├── Outbox insert + status transitions
│   ├── FTS5 search (insert message, search by subject/body)
│   └── Rate limiting (checkRateLimit, recordLoginFailure)
└── Summary (pass/fail count, exit code 0 on success, 1 on failure)
```

**Test count estimate:** ~80-100 test cases

**Key decisions:**
- Use `ReflectionMethod` to test private IMAP methods (`tokenize`, `parseFetchItems`)
- Each test gets a fresh temp SQLite DB (auto-cleanup after group)
- Set `EMMMAIL_DB` env var to temp path before requiring index.php
- Set `EMMMAIL_KEY` env var to a fixed test key for deterministic encryption tests
- No network calls — all tests are local
- Color output: green ✓ for pass, red ✗ for fail
