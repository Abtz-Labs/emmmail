# Favicon: "E." in Nord dark

## Goal
The browser tab shows an Emmmail icon. Inline SVG, no new file, no new route.

## Design (32x32 viewBox, `xmlns` required: an SVG loaded as an image needs it)
- Rounded square, `rx=7`, fill nord0 `#2e3440` (dark `--bg`).
- "E" as one path, not `<text>`: a favicon cannot rely on a font. Fill nord6 `#eceff4`
  (dark `--text`). `x 7-19`, `y 7-25`, bars 4 units, gaps 3 units, integer grid, so it
  stays sharp at 16px.
- "." as a circle `cx=24 cy=22 r=3`, bottom on the E's baseline, fill nord8 `#88c0d0`
  (dark `--accent`).
- Same icon in both themes. On a dark tab bar the tile edge is faint; the light E reads.

## Change
`render_page()` `<head>`: one `<link rel="icon" type="image/svg+xml" href="data:image/svg+xml,...">`.
The SVG is built with `rawurlencode()`, so no `"`, `#`, `<` or `>` reaches the attribute. The CSP already allows `img-src data:`. Every page uses
`render_page()`, the login page too.

## Tests (red first)
- unit, on the existing logged-out `$page` (the login path): the icon link is there.
- unit: the `href` payload, `rawurldecode`d, parses as XML, has the SVG `xmlns`, and has
  the three Nord colours (Nord is the requirement).

## Verification
- `just test` green.
- Manual: the tab shows the icon in Chromium, Firefox and Safari 26+ (older Safari shows
  a letter tile). Not run by the agent.
